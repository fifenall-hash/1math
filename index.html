📲 태블릿/모바일 앱 설치 안내

  • 설치가 안 되어 있는데 '이미 설치됨/앱 열기'라고 나올 때:
    안드로이드 [설정 → 애플리케이션] 목록에서 예전에 설치했던 덧셈 놀이터나 같은 깃허브 계정의 다른 웹앱을 찾아 '삭제(제거)'한 뒤 다시 접속하면 정상 설치됩니다.
  • 아이패드 / 아이폰 (Safari·Chrome):
    브라우저의 [공유(↑) 버튼 → 홈 화면에 추가]를 누르면 전체화면 앱으로 설치됩니다.
  • 안드로이드 크롬 수동 추가:
    우측 상단 [점 3개(⋮) 메뉴 → 홈 화면에 추가(또는 앱 설치)]를 눌러주세요.
